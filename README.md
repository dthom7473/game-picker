This web application uses javascript and libraries to create a rotating pie chart emulating a "wheel of fortune" type application. Games can be added dynamiacally to allow users to fully customize the options acording to their needs! The project was created to practice core JavaScript concepts including arrays, DOM manipulation, event listeners, animations, and the use of external libraries such as Chart.js.

Additional code used within this project can be found in this folder, such as the html and css files.

The purpose of this software is to demonstrate basic JavaScript understanding.

A link to the application demonstration video can be found here:
[https://youtu.be/EkOVJ7aUd7w]

# Development Environment
There were a handful of tools used, primarily found in the links below. In addition to those useful tutorials, I used the Claude engine incorperated into VisualStudioCode to assist me with syntax errors and program bugs, such as a wheel alignment bug, dynamic slice count offset bug, spin animation jittering, and external library incorperation. The chart file references and libraries were found from an open source tutorial while researching for this project.
